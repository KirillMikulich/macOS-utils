# Ручной чек-лист тестирования (на настоящем Mac)

Отмечайте результат и версию macOS. Пункты с ✅ проверены при разработке на macOS 27.0.1 (сборка Debug, ad-hoc подпись); остальные требуют выданных разрешений и/или взаимодействия пользователя.

## Приложение
- [x] ✅ Приложение запускается, в строке меню появляется значок отвёртки, значка в Dock нет.
- [x] ✅ Главное окно: боковая панель, Dashboard с тремя карточками, переключатели и статусы.
- [ ] Закрыть главное окно → история буфера продолжает записываться.
- [ ] Меню строки меню: включение/выключение модулей, «Приостановить все модули» (значок становится приглушённым), «Выйти».
- [ ] Тема: «Светлая» / «Тёмная» / «Как в системе» в разделе «Основные»; переключение системной темы.
- [ ] Значок в Dock включается и выключается.
- [ ] Запуск при входе: включить → выйти из системы и войти → приложение запущено, окно не открылось (если выключено «Открывать окно при запуске»).
- [ ] Повреждённый файл: записать мусор в `~/Library/Application Support/Otvertka/Settings/clipboardHistory.json` → перезапуск → настройки по умолчанию, рядом `*.corrupt-*.json`.
- [ ] Настройки сохраняются после перезапуска (изменить лимит истории, сочетание клавиш, включение модуля).

## Clipboard History
- [x] ✅ Обычный текст и Unicode (кириллица, эмодзи) записываются автоматически.
- [x] ✅ PNG-изображение записывается как изображение с исходным разрешением (512×512, исходные байты).
- [x] ✅ ⌥⇧V открывает панель поверх активного приложения; активное приложение не меняется.
- [x] ✅ ↓ + ↩ кладёт выбранный элемент в системный буфер; фокус остаётся в исходном приложении.
- [x] ✅ Поиск в панели + ↩ восстанавливает изображение как PNG (проверено `clipboard info`).
- [ ] Скриншот в буфер: ⌃⇧⌘4 / ⌃⇧⌘3 → в истории миниатюра, вставка в «Заметки»/Pages даёт изображение.
- [ ] «Копировать изображение» в Safari и Chrome → элемент типа «Изображение».
- [ ] Изображение из Telegram / Preview / Pixelmator.
- [ ] Форматированный текст из Pages/Word/Safari → вставка в TextEdit (RTF) сохраняет форматирование.
- [ ] Файлы в Finder (⌘C на нескольких файлах) → тип «Файлы», вставка в Finder копирует файлы.
- [ ] Повторное копирование того же текста не создаёт дубликат.
- [ ] Лимит 10/20/50/100 и своё значение; закреплённые элементы не удаляются.
- [ ] Удаление элемента (⌘⌫ в панели), закрепление (⌘P), очистка истории.
- [ ] Режим приватности: копирование не записывается; индикатор в панели.
- [ ] Исключённое приложение (например, «Пароли»): копирование не записывается.
- [ ] Пароль из 1Password/Bitwarden не записывается (маркер Concealed).
- [ ] Выключить «Сохранять историю между перезапусками» → файлы `ClipboardHistory/items` удалены; после перезапуска история пуста.
- [ ] Режим «Скопировать и сразу вставить» с выданным Accessibility: текст вставляется в TextEdit.
- [ ] Выключить модуль → копирование не записывается, ⌥⇧V не открывает панель.
