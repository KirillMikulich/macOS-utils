# Известные ограничения macOS

## Общие
- **App Sandbox невозможен.** Accessibility API для чужих окон, наблюдение за Dock и отправка ⌘V не работают в песочнице, поэтому приложение не может распространяться через Mac App Store. Hardened Runtime включён.
- **Разрешения привязаны к подписи.** При ad-hoc подписи (без команды разработчика) каждая пересборка — для macOS «другое приложение»: Accessibility и Screen Recording приходится выдавать заново (удалить запись кнопкой «–» и добавить снова). Подпись своим Apple ID решает проблему.
- **Screen Recording** иногда применяется только после перезапуска приложения. Начиная с macOS 15 система периодически переспрашивает подтверждение для приложений с доступом к записи экрана.

## Горячие клавиши
- ⌘⇥ перехватывается переключателем окон через CGEventTap (нужен «Универсальный доступ»), только пока Otvertka запущена. Если перехватчик отключится (например, после отзыва разрешения), снова сработает системный переключатель приложений.
- Сочетания, которые обрабатывает сама macOS раньше приложений (⌘⇥, ⌘`, ⌘Space, снимки экрана и т.д.), перехватить нельзя. Приложение предупреждает об известных из них, но пользовательские системные сочетания (*Клавиатура → Сочетания клавиш*) и сочетания других приложений обнаружить нельзя: `RegisterEventHotKey` в этом случае обычно не возвращает ошибку.
- ⌥⇥ по умолчанию не занят системой, но может использоваться отдельными приложениями (например, для перехода по вкладкам) — пока переключатель включён, приложение его перехватывает.

## Clipboard History
- В macOS нет события «буфер изменился» — используется опрос `changeCount`. Очень быстрые последовательные копирования (чаще интервала опроса) записываются как одно, последнее.
- Приложение-источник определяется как активное приложение в момент обнаружения изменения. Если копирование сделано фоновым процессом, источник может быть указан неверно, и исключения по приложениям в этом случае не сработают.
- Распознавание секретов основано только на маркерах nspasteboard.org, которые выставляет приложение-источник. Пароль, скопированный из приложения без такой метки, будет записан. Эвристик для паролей и одноразовых кодов нет намеренно — они ненадёжны.
- File promises (перетаскивание из некоторых приложений, фото из «Фото» без экспорта) не сохраняются — их данные нельзя воспроизвести позже. Скопированные файлы сохраняются как ссылки на файлы, а не их содержимое: если файл удалён или перемещён, вставка не сработает.
- Автовставка (⌘V) зависит от приложения-получателя; защищённые поля ввода (Secure Input, например поля паролей) блокируют синтетические нажатия.
- История на диске не шифруется отдельно (защищена FileVault, если он включён).

## Window Switcher
- Через публичный Accessibility API видны окна только **текущего рабочего стола (Space)** и свёрнутые окна. Окна на других Spaces и полноэкранные приложения на других Spaces не показываются (AltTab получает их через закрытые API SkyLight — здесь они не используются).
- Миниатюру свёрнутого окна получить нельзя: показывается последняя миниатюра из текущего сеанса или значок приложения.
- Приложения, которые не реализуют Accessibility (некоторые игры, Java/кроссплатформенные приложения), могут не отображаться или не активироваться корректно.
- Получение `CGWindowID` использует недокументированную `_AXUIElementGetWindow`. Если Apple её уберёт, сработает запасной вариант (сопоставление по рамке), менее точный для окон с одинаковыми размерами.

## Dock Preview
- **Системный Dock не изменяется.** Сторонние приложения не могут встроиться в Dock или заменить его поведение. Модуль наблюдает за Dock через Accessibility и показывает собственную панель рядом со значком.
- Предпросмотр показывается только для запущенных приложений с окнами на текущем Space.
- Положение панели вычисляется по рамке значка из Accessibility; ориентация Dock читается из настроек `com.apple.dock`. При нестандартных конфигурациях (несколько дисплеев с Dock на разных экранах) возможно неидеальное позиционирование.
- Щелчок по значку Dock выполняет обычное действие Dock; панель при этом скрывается.

## Снимки экрана в истории
- Начиная с macOS 26 папка снимков, выбранная в «Снимок экрана» (⌘⇧5 → Параметры → Сохранить в), хранится в защищённом контейнере утилиты. Сторонние приложения не могут ни прочитать, ни изменить её: команда `defaults write com.apple.screencapture location` на macOS 27 игнорируется (проверено). Поэтому папку и плавающую миниатюру нужно настраивать в ⌘⇧5, а Otvertka следит сразу за Рабочим столом, «Документы/Снимки экрана» и папкой из старой настройки. Снимок из другой выбранной папки Otvertka не увидит.
- На macOS 14–15 кнопка в настройках Otvertka задаёт папку и отключает миниатюру напрямую.
- Пока после снимка видна плавающая миниатюра (~5 с), macOS не сохраняет файл, поэтому снимок попадает в буфер с задержкой. Миниатюра выключается в ⌘⇧5 → Параметры.
- Для доступа к Рабочему столу или Документам macOS один раз спрашивает разрешение (раздел «Файлы и папки»).
- Снимки, сохранённые сразу в Буфер обмена (с ⌃), попадают в историю обычным путём, через мониторинг буфера.

## Мышь и Dock
- Колесо мыши перехватывается через CGEventTap (нужен «Универсальный доступ»): щелчок колеса заменяется серией плавных «пиксельных» событий прокрутки. Трекпад и Magic Mouse не затрагиваются; с ⌘ или ⌃ колесо работает как обычно. Отдельные приложения можно исключить.
- Пауза и анимация Dock — публичные настройки `com.apple.dock`; Dock читает их только при запуске, поэтому при каждом применении он на мгновение перезапускается (окна не закрываются). Настройки действуют только при включённом автоскрытии Dock.
- Ускорение и скорость указателя меняются только в Системных настройках → Мышь: применить их на лету умеет только сама macOS (через закрытый API), поэтому Otvertka показывает их состояние и открывает нужный раздел.
- Переназначение кнопок мыши пока не реализовано.

## Автовыход
- Закрытие окна отслеживается через Accessibility; различить «красную кнопку» и ⌘W нельзя — завершение срабатывает в обоих случаях.
- Accessibility видит окна только текущего рабочего стола. Чтобы не закрыть приложение с окном на соседнем рабочем столе, Otvertka запоминает окна приложения и проверяет их по CGWindowList на всех рабочих столах. Если приложение было запущено до Otvertka и его окно находится на другом рабочем столе, которое Otvertka ещё не видела, такое окно не учитывается — добавьте приложение в исключения, если это важно.
- Приложения, которые работают без окон (плееры, мессенджеры), стоит добавить в исключения.

## Скриншот
- Нужно разрешение «Запись экрана». Снимается экран, на котором находится курсор; выделение через несколько мониторов сразу не поддерживается.
- Загрузки в облако и коротких ссылок (как в Lightshot) нет намеренно: приложение не использует сеть.
- Пометку можно выбрать, переместить и поменять ей цвет, толщину и размер текста; изменить форму (например, длину стрелки) после рисования нельзя — отмените (⌘Z) и нарисуйте заново.

## Удаление программ
- Файлы ищутся по идентификатору приложения, по точному названию папки и по команде разработчика из подписи. Программы, которые раскладывают файлы под другими именами, могут оставить «хвосты» — их можно найти и удалить вручную.
- Без «Полного доступа к диску» часть данных других приложений не видна, и macOS отдельно спрашивает доступ к ним.
- Системные приложения Apple защищены macOS (SIP) и не удаляются. Файлы администратора удаляются через Finder с запросом пароля; для этого macOS один раз спросит разрешение на управление Finder.
