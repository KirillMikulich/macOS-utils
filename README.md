# Mac Utilities

Открытый (open source) набор утилит для macOS в одном приложении. Живёт в строке меню, каждая утилита включается отдельно. Весь исходный код — в этом репозитории. Данные хранятся только на вашем Mac, сеть не используется.

## Установка

Готовые сборки лежат в папке [builds](builds/): `Mac-Utilities-<версия>.dmg`. Нужна macOS 14 или новее.

1. Откройте DMG и перетащите Mac Utilities в «Программы».
2. Приложение не нотаризовано Apple, поэтому первый запуск macOS заблокирует. Откройте Системные настройки → Конфиденциальность и безопасность → «Всё равно открыть». Или в Терминале: `xattr -dr com.apple.quarantine "/Applications/Mac Utilities.app"`.
3. Для переключателя окон и предпросмотра в Dock macOS попросит «Универсальный доступ» и «Запись экрана».

## Утилиты

### История буфера обмена
Запоминает всё, что вы копируете: текст, ссылки, форматированный текст, картинки, файлы и снимки экрана. **⌥⇧V** открывает список: щелчок или ↩ вставляет элемент в текущее приложение, ⇧↩ — только копирует. Поиск, закрепление важных элементов (⌘P), очистка одной кнопкой, режим приватности и исключения для менеджеров паролей. Новый снимок экрана сразу попадает в буфер — можно вставлять ⌘V.

### Переключатель окон
Как Alt+Tab в Windows: **⌘⇥** показывает миниатюры всех окон (не только приложений), отпустите ⌘ — переход к выбранному. ⌘⇧⇥ — назад, стрелки — выбор, ⌘W / ⌘M / ⌘Q — закрыть окно, свернуть, завершить приложение. Размер миниатюр, отступы, режим «только значки», сортировка и группировка настраиваются.

### Предпросмотр окон в Dock
Наведите курсор на значок в Dock — над ним появятся миниатюры окон приложения; щелчок переключает на окно. Кнопки «закрыть», «свернуть», «завершить» прямо на миниатюрах. **⌥⇧W** — окна текущего приложения по центру экрана.

### Скриншот
**⌥⇧S** — выделите область экрана, и откроется редактор: стрелки, прямоугольники, овалы, линии, карандаш, маркер, текст, размытие, нумерация, обрезка и изменение размера. Цвет, толщину и размер текста можно менять у уже нарисованного, пометки перетаскиваются. ⌘C — скопировать, ⌘S — сохранить.

### Мышь и Dock
Плавная прокрутка колесом мыши, как на трекпаде: шаг, скорость и длительность доката, ⌥ + колесо — быстрая прокрутка, список приложений без плавности. Отдельное направление прокрутки для мыши — независимо от трекпада и «естественной прокрутки». Dock при автоскрытии выезжает без задержки и быстрее.

Плавная прокрутка перенесена из [Mos](https://github.com/Caldis/Mos) (автор — Caldis, лицензия [CC BY-NC 4.0](https://creativecommons.org/licenses/by-nc/4.0/)): интерполяция, сглаживающий фильтр, значения по умолчанию и доставка событий приложению.

### Автовыход
Закрыли последнее окно приложения — приложение завершается, как в Windows. Можно включить для всех приложений с исключениями или только для выбранных.

### Удаление программ
Удаляет приложение вместе с его настройками, кэшами, контейнерами и другими файлами в Library. Показывает найденное с размерами, всё уходит в Корзину — можно вернуть.


## Сборка из исходников

Откройте `MacUtilities.xcodeproj` в Xcode и запустите схему **MacUtilities**. В проекте указана команда разработчика автора — для сборки на своём Mac выберите свою в Signing & Capabilities.

`Scripts/make_dmg.sh` собирает Release-версию, увеличивает номер версии и кладёт DMG в `builds/`.

- `MacUtilities/` — код приложения
- `MacUtilitiesTests/` — тесты
- `Documentation/` — архитектура, известные ограничения, чек-лист ручной проверки
