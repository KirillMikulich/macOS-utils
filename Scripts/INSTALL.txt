Mac Utilities — установка

1. Перетащите Mac Utilities.app в папку «Программы» (Applications).

2. Первый запуск. Приложение подписано сертификатом разработчика, но не нотаризовано Apple,
   поэтому macOS при первом открытии его заблокирует. Это нужно сделать один раз:
   - откройте Mac Utilities из «Программ» — появится предупреждение, нажмите «Готово»;
   - Системные настройки → Конфиденциальность и безопасность → внизу «Mac Utilities заблокирован…»
     → «Всё равно открыть» → подтвердите паролем.
   (Вариант для Терминала: xattr -dr com.apple.quarantine "/Applications/Mac Utilities.app")

3. В строке меню появится значок ключа и отвёртки, откроется окно настроек.
   История буфера обмена работает сразу: ⌥⇧V — открыть панель истории.

4. Переключатель окон (⌘⇥) и предпросмотр окон в Dock включаются в окне настроек.
   macOS попросит разрешения:
   - «Универсальный доступ» — обязательно (переключение окон, наблюдение за Dock, автовставка);
   - «Запись экрана и аудио» — для миниатюр окон (после выдачи перезапустите Mac Utilities).
   При первом снимке экрана macOS может спросить доступ к Рабочему столу —
   это нужно, чтобы снимки появлялись в истории.

Интерфейс по умолчанию на английском; русский включается в General → Language.

Все данные хранятся только на этом Mac (~/Library/Application Support/Mac Utilities),
приложение не использует сеть.
